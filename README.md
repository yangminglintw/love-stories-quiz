# Love Stories Quiz 愛情故事測驗

基於 Sternberg 的 26 種愛情故事理論的互動測驗

## 📋 專案資訊

- **來源**: Sternberg, R. J. (1998). *Love is a Story*
- **題數**: 224 題（26 種故事類型）
- **技術棧**: HTML + Tailwind CSS + Chart.js
- **部署**: GitHub Pages

## 🎯 MVP 功能

1. ✅ 224 題依序顯示（中英對照）
2. ✅ 計算 26 類型平均分
3. ✅ Radar Chart 視覺化
4. ✅ Top 5 類型 + 詳細說明
5. ✅ 進度條

## 📁 檔案結構

```
love-stories-quiz/
├── index.html          # 主頁面
├── questions.json      # 題目資料
├── translations.json   # 中文翻譯
├── styles.css          # 自訂樣式
├── app.js              # 測驗邏輯
└── README.md
```
